# 亚博GNSS：当前连接与接入状态

更新日期：2026-10-14。模块为ATGM336H-5N载板，本阶段完成直接USB串口通信检查；户外定位与ESP32固件接入尚未完成。

## 当前已使用的连接

| GNSS接口 | 连接对象 | 状态 |
|---|---|---|
| 模块自身USB | 电脑USB（测试时） | 供电及板载USB转串口NMEA读取 |
| VCC/GND/TX/RX排针 | 未连接ESP32 | 不属于当前ESP32采集接线 |

此前USB桥识别为CH340，历史端口COM8；端口号可能变化，使用设备管理器或串口诊断工具识别实际端口。已检查9600 baud、8N1、约1 Hz NMEA及校验；室内没有有效卫星定位。USB通信通过不代表已定位。

诊断工具为`tools/serial_diagnostics/gnss_usb.py`，只读检查，不改接收机配置；关闭占用该端口的其他监视器再使用。

## 后续UART连接属于规划

之前提出使用ESP32 UART2、IO16作RX接GNSS TX；目前没有对应board_config宏，也没有UART2驱动初始化，因此不能把IO16写成已连接或已启用。GNSS RX对应的ESP32 TX脚尚未确定。

正式接入时先核对载板供电及串口电平，再确定VCC/GND、GNSS TX→ESP32 RX以及是否需要GNSS RX命令线。不要将GNSS芯片供电范围直接作为载板VCC接法，也不要现在额外补接尚未确认的电源或信号线。

资料位于上级项目`数据手册/亚博智能GPS模块`。当前统一GPIO占用见 [hardware.md](hardware.md)。手表定位页保留“未接入”和缺失值；下一步在具备户外条件后完成有效定位、UTC、卫星和定位质量验证，再加入ESP32串口采集。
