# 山知 SummitSense｜阶段工作进展报告

**更新日期：2026年10月14日**

**当前阶段：多传感器原型采集与手表界面开发**

## 一、阶段成果

已建立基于ESP32-S3的原型系统，形成“传感器采集—串口传输—PC记录与展示”的基本链路，并完成设备端第一版中文界面。当前以单模块功能验证为主，尚未完成可穿戴整机联合验证。

| 工作方向 | 已完成内容 | 当前状态 |
|---|---|---|
| 基础工程 | ESP-IDF环境、烧录、系统监测、模块化组件与Git管理 | 主控及Flash/PSRAM运行验证通过 |
| 生理采集 | MAX30102双通道PPG约100 Hz采集、心率与血氧实验估算、信号有效性判断 | 已实现实物采集与效果展示；准确性对照待完成 |
| 运动与环境 | 十轴IMU加速度、角速度、姿态、气压及气压高度；AS6221温度读取 | 单模块功能验证通过，气压高度未校准 |
| PC工具 | 实时曲线、三维姿态、数据保存、质量统计与串口自动诊断 | 支持实验记录与问题追溯 |
| 屏幕与界面 | ST7789S屏幕驱动、七页LVGL中文界面、按键翻页与自动轮播 | 屏幕及方向已验证；整套UI实屏验收待完成，当前使用演示数据 |
| 定位 | GNSS直接USB连接与NMEA通信检查 | 通信通过；户外定位及ESP32接入待完成 |

现有固件构建通过，15项协议与算法测试通过；界面预览覆盖14种页面状态，连续210次页面切换未发现分配残留。软件检查用于验证实现，不能替代测量准确性及实机长期稳定性验证。

## 二、主要问题与解决方式

| 问题 | 处理方式与结果 |
|---|---|
| IMU有运动数据，但缺少气压和高度 | 通过自动串口诊断确认模块未输出气压帧；改用模块自身USB开启并保存输出配置，断电回接后成功接收。当前采用三线接收，ESP32向IMU发送配置的通路仍待排查。 |
| 温度变化显示存在延迟 | 将转换与读取目标从1 Hz提高至4 Hz，减少软件更新等待。功能反馈正常，接触热惯性与结构影响仍需量化。 |
| 屏幕整体左右镜像 | 调整显示控制器方向参数，实屏方向恢复正常。 |
| 手动复制串口日志效率低 | 增加自动采集、筛选及诊断工具，保留原始日志和统计结果，提高排查与复现效率。 |

## 三、当前不足与所需条件

- **测量精度尚未验证：** 缺少可靠参考心率、血氧及温度设备。血氧保留未标定标识，气压海拔需建立基准；当前数值用于原型展示。
- **联合验证条件不足：** PPG与IMU尚未固定在同一可穿戴结构，无法进行有代表性的共同运动测试；需要稳定固定、遮光和接触结构。
- **界面与真实数据尚未打通：** 七页UI已完成，但数据绑定、过期/无效状态联动及触摸交互仍待开发。
- **定位与整机能力不完整：** GNSS需户外条件验证；步数算法、电池供电、功耗及独立存储尚未完成。当前通过PC保存记录。

## 四、下一步计划

1. **完成界面验收：** 检查实屏排版、中文、颜色、按键翻页与轮播，完善交互体验。
2. **接入真实数据：** 建立统一数据快照和有效性管理，将生理、温度、姿态及气压替换为实时值，再开展显示与采集联合验证。
3. **完善触摸与定位：** 接入触摸导航；具备户外条件后验证GNSS并接入固件。
4. **推进整机验证：** 固定各模块后开展运动、温度响应及长期稳定性测试；具备参考设备后进行误差评估与标定，再推进供电、功耗和结构设计。
