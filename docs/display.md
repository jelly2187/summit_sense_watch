# TK013F2261 V1.3显示与触摸接线

## 当前接线（2026-10-14）

实物PCB丝印为TK013F2261_V1.3，240×240，ST7789S SPI显示。上方连接器为SDA/SCL/3.3V/GND，下方为CS/SCK/DC/MOSI，按丝印认线，不按线色判断。V1.2资料中的TP1接法不适用于此板。

| 连接器 | 屏幕引脚 | ESP32-S3 | 当前用途 |
|---|---|---|---|
| 上接口 | 3.3V | 3V3 | 屏幕/载板供电 |
| 上接口 | GND | GND | 共地 |
| 上接口 | SDA | **留空** | 触摸I²C数据，尚未接入 |
| 上接口 | SCL | **留空** | 触摸I²C时钟，尚未接入 |
| 下接口 | CS | IO13 | SPI2片选 |
| 下接口 | SCK | IO12 | SPI2时钟 |
| 下接口 | DC | IO14 | 命令/数据选择 |
| 下接口 | MOSI | IO11 | 主控向LCD发送数据 |

改线前断电，共地。无MISO接线；上接口SDA/SCL不能代替下接口MOSI/SCK。该板没有外露RST或BL_CTR接口，**不接IO15/IO21**。使用软件复位，当前背光随供电工作，没有软件亮度调节。统一接线见 [hardware.md](hardware.md)。

## 当前显示模式与参数

显示/颜色及水平镜像修正已由用户目视确认。参数集中在board_config：SPI2、模式0、10 MHz、RGB565、BGR=1、INVERT=0、X/Y偏移0；MADCTL的MX=1、MY=0，修正左右镜像。

`display_panel`统一维护已验证的厂家初始化配置与SPI DMA传输。默认入口启动`watch_ui`，显示七页LVGL中文演示界面；不是启动RGB测试图。短按开发板BOOT翻页，长按1秒切换8秒轮播，BOOT为板载GPIO0，无需外接线。具体界面状态见 [watch_ui.md](watch_ui.md)。

UI使用两块240×40×2字节内部DMA缓冲。独立`display_test`仍可用于诊断，使用240×20×2=9600字节缓冲，每20行分块发送；红/绿/蓝各约0.7秒后显示边框、TOP、四角标志与色条。两种模式复用panel，不能同时启动。SPI完成回调到达后才复用缓冲。

## 触摸尚未接入

CST816D触摸功能未启用，上接口SDA/SCL均留空，无当前GPIO分配。I²C0已用于MAX30102、I²C1已用于AS6221；后续触摸需共享其中一条总线并统一驱动资源，不能创建第三个硬件I²C控制器。当前看完整界面不需要增加触摸线。

## 验收与排查

串口LCD日志只证明发送了命令/图像，不是硬件应答或身份认证。每次改线/方向后目视检查：颜色正常、中文字形不镜像、边缘完整、翻页无大片错行；原有串口采集继续运行。

背光不亮先核对上接口3.3V/GND，不把板上BL元件标注当外接GPIO。有背光但无画面时检查下接口四线、CS/DC和初始化配置。已验证的MX/BGR/反色与偏移保留；不要为接线排查随意改FPC引脚。七页UI实屏验收与长期运行记录另行确认，不等同已通过的独立色块/方向测试。
