# TK013F2261 V1.3 显示初测

用户实物照片确认V1.3板：上方接口SDA/SCL/3.3V/GND，下方CS/SCK/DC/MOSI。MOSI已引出，V1.2资料中的TP1接法不适用于此板。

断电接线：3.3V→3V3、GND→GND、CS→IO13、SCK→IO12、DC→IO14、MOSI→IO11。上方SDA/SCL是触摸接口，首轮留空。没有外部RST或BL_CTR接口，不接IO15/IO21。使用软件复位；背光默认行为需实测。

新增display_test组件，SPI2、模式0、10 MHz、RGB565。初始化参数参考随资料提供的TK013F2261显示配置，由本项目独立实现驱动；本轮没有复制LVGL项目或引入触摸库。默认BGR、不反色、X/Y偏移0，可在board_config按实际效果调整。

上电后显示全屏红、绿、蓝各约0.7秒，再保留静态测试图：白色1像素边框、上方TOP、四角TL/TR/BL/BR、从左至右R/G/B三色块和灰阶条。字母用于确认方向，灰阶用于初步查看像素格式和传输异常。触摸、字体UI、传感器数值显示和LVGL尚未加入。

内部DMA缓冲为240×20×2=9600字节；按20行分块发送，等待传输完成回调后复用，不申请全屏双缓存。低优先级独立任务一次性绘制；已有PPG、IMU、温度和心跳任务继续运行。

串口# LCD日志只证明主控发送了命令和图像，不是LCD硬件应答或身份认证。烧录后需目视确认：

1. 有背光与完整图像，四条边框均可见，没有大面积空白条。
2. R/G/B颜色顺序正确，TOP位于预期上方，四角字母不镜像。
3. 图像静止时没有闪烁或错行，串口采集继续正常。

若背光不亮，先检查3.3V和GND及V1.3背光电路；不要随意把板上的BL元件标注当外接GPIO。若有背光但无图像，检查SPI四线、DC/CS、软件复位与配置；颜色交换可调整BGR，反色可调整INVERT；偏移或裁切再核对地址窗口与安装方向。不要未经确认改FPC引脚。

下一轮在该面板验证通过后引入LVGL与统一数据快照，再显示估算值和有效状态；触摸需整理共享I²C资源。目前两个I²C总线已分别用于PPG和AS6221，不能直接创建第三个控制器。
