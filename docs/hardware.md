# 硬件与接线

## 当前主板

微雪ESP32-S3-DEV-KIT-N16R8，16 MB Flash、8 MB PSRAM。Flash使用DIO 80 MHz，PSRAM使用Octal 80 MHz；两者模式不要混淆。

当前引脚和I²C速度统一维护在 `components/board_config/include/board_config.h`。

## MAX30102

断电后接线，GPIO号对应板上丝印，不是排针位置序号。

| 野火模块 | 开发板 | 状态 |
|---|---|---|
| 3V3 | 3V3 | 3.3V供电 |
| GND | GND | 共地 |
| SDA | IO8 | I²C数据 |
| SCL | IO9 | I²C时钟 |
| INT | IO10 | 已分配；当前未使用 |

模块已有上拉电阻，启动检查关闭主控内部上拉。I²C初始速度100 kHz，使用7位地址0x57，不填写带读写位的0xAE或0xAF。

PART_ID寄存器0xFF期望返回0x15，REV_ID寄存器0xFE随芯片版本变化。启动检查读取器件信息；检查通过后开启100 Hz红光与红外原始采样。INT保持未使用，当前采用10 ms轮询。

| 模块 | 接口计划 | 当前状态 |
|---|---|---|
| 亚博十轴IMU | UART1 | 默认9600 baud、10 Hz，尚未接入 |
| 亚博GNSS | UART2 | 默认9600 baud、8N1、1 Hz NMEA，尚未接入 |
| AS6221 | I²C | 尚未接入 |
| 1.3寸240×240彩色方屏 | SPI | 驱动芯片、接线待确认 |

超声波和microSD暂缓。GNSS载板供电与芯片供电须区分，各模块逻辑电平和总线配置核对后再接线。

厂家资料位于上级项目 `数据手册/10轴IMU惯导模块`、`数据手册/野火小智心率血氧模块资料_20241220`和 `数据手册/亚博智能GPS模块`，保持原目录。

## IMU当前接线

IMU 5V→主板5V、GND→GND、TX→IO18、RX→IO17。UART1默认9600/8N1；第四根线用于请求开启气压输出。软件驱动和PC展示已实现，实物验证待完成；详细说明见imu.md。

当前实际使用USB预配置后的三线接收：5V/GND/TX→IO18，RX留空。气压输出设置已保存并经断电回接验证；原四线接法是待排查的在线配置方式，详见imu.md。
